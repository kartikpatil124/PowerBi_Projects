✈️ Flight Delay & Cancellation Analysis Dashboard
📌 Project Overview

The Flight Delay & Cancellation Analysis Dashboard is an enterprise-level Business Intelligence solution developed using Power BI to analyze airline operational performance from 2019–2023.

The project provides insights into flight operations, delays, cancellations, airport performance, route efficiency, and time-based trends. It follows industry-standard Star Schema data modeling, professional DAX calculations, and interactive dashboard design principles used by Business Intelligence teams.

🚀 Project Objectives
Analyze overall airline operational performance.
Monitor flight delays and cancellation trends.
Compare airline and airport performance.
Identify the major causes of delays.
Discover poorly performing routes.
Support data-driven operational decisions.
