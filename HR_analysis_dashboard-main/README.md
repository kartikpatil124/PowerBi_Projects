## 📌 Project Overview

Modern organizations generate massive volumes of HR data every day—from recruitment and employee demographics to engagement surveys, performance reviews, and training records. However, raw data alone cannot drive strategic workforce decisions.

This project demonstrates how enterprise HR data can be transformed into a scalable Business Intelligence solution that enables HR leaders and executives to monitor workforce health, identify performance trends, improve employee retention, and make data-driven decisions.

The solution follows industry-standard BI development practices including:

- Data Cleaning (Power Query)
- Data Modeling (Star Schema)
- Business KPI Development (DAX)
- Interactive Dashboard Design
- HR Business Analysis

---

# 🎯 Business Problem

HR departments often struggle with:

- High employee attrition
- Low employee engagement
- Performance tracking
- Workforce planning
- Recruitment monitoring
- Training effectiveness
- Lack of centralized reporting

This dashboard addresses these challenges by providing a centralized analytics platform for HR decision-makers.

# 📊 Data Modeling

The project follows a Star Schema architecture.

Employee Data serves as the central table connected with:

- Employee Engagement
- Performance
- Recruitment
- Training

using Employee ID as the primary relationship key.
